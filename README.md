# 🌍 Portfolio Delivery Using Amazon CloudFront (CDN)

This repository contains my portfolio files delivered globally using **Amazon CloudFront**, with an **Amazon S3 bucket** as the origin.

## 🚀 Live CloudFront URL
https://d3csn95wctzwna.cloudfront.net

## 🗂 S3 Website (Origin)
http://srimahalakshmi-portfolio.s3-website.ap-south-1.amazonaws.com

## 📁 Files Included
- `index.html`
- `style.css`
- `resume.pdf`

## 📝 CloudFront Setup Steps
1. Selected **Amazon S3** bucket as origin.
2. Set origin access to **Public**.
3. Added **index.html** as Default Root Object.
4. Created CloudFront distribution.
5. Waited for deployment.
6. Tested CloudFront global URL.

## 🛠 AWS Services Used
- Amazon S3  
- Amazon CloudFront
